## 📚 Sobre o Curso

O curso **Front-end Developer** da CESAE Digital tem como objetivo formar profissionais capazes de desenvolver interfaces modernas, funcionais e responsivas, dominando as principais tecnologias da web — do HTML/CSS/JS puro até frameworks modernos (React) e desenvolvimento full-stack com Laravel.

🕒 **Duração:** 1050 horas
🏫 **Modalidade:** Presencial
🎯 **Objetivo:** Criar e desenvolver aplicações web client-side e server-side, aplicar metodologias ágeis (Scrum, Kanban), e desenvolver competências técnicas e criativas para o mercado digital.
🌐 **Mais informações:** [cesaedigital.pt](https://www.cesaedigital.pt/curso/lista/front_end_developer_sjm_v1)

## 🌟 Projetos em destaque

### 🍽️ CasaPortuguesa (React)
Aplicação de encomendas online de um restaurante português, com:
- Front-end em **React 19** + **React Router v7** + **React-Bootstrap**
- Autenticação com contexto próprio (`AuthContext`) e rotas protegidas por perfil (`customer`, `kitchen`, `manager`)
- Backend próprio em **Node.js/Express** com upload de imagens (`multer`) e persistência em ficheiro JSON
- Páginas para cliente (pedido, acompanhamento de encomenda), administração (cozinha e gestor)

### 🎬 Laraflix (Laravel)
Plataforma de streaming inspirada na Netflix, com:
- **Laravel 12** + Breeze (autenticação) + Tailwind + Vite
- Gestão de perfis por conta (semelhante à Netflix), com permissões de admin
- Watchlist pessoal, categorias de filmes e integração com a **API OMDb** para dados dos filmes
- Migrations, seeders e serviços dedicados (`OmdbService`)

### 🕹️ Universo dos Jogos (HTML/CSS/JS)
Portal com três mini-jogos desenvolvidos em JavaScript puro (sem frameworks):
- Jogo da Memória, Jogo de Reflexos e Snake
- Site institucional com páginas de história/apresentação e contacto

### 📊 GameStart (Java)
Sistema de consola para gestão de vendas de uma loja de jogos, com leitura/escrita de dados a partir de um ficheiro CSV e dois modos de utilização (Administrador e Cliente).
